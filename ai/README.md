# AI Component - Smart Electronics

This directory contains the AI/Machine Learning models, preprocessing scripts, dataset pipeline, training routines, and explainability modules for the Smart Electronics system.

- **[prediction/](file:///c:/Users/Pradeep/Desktop/smart_electronics/ai/prediction/)**: Inference and prediction pipelines.
- **[explainability/](file:///c:/Users/Pradeep/Desktop/smart_electronics/ai/explainability/)**: SHAP/LIME or other model explanation scripts.
- **[utils/](file:///c:/Users/Pradeep/Desktop/smart_electronics/ai/utils/)**: Helper functions, logging, and common utilities.
- **[tests/](file:///c:/Users/Pradeep/Desktop/smart_electronics/ai/tests/)**: Unit tests for data, preprocessing, training, and models.
